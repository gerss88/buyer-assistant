# Локальный ИИ-помощник покупателя

Минималистичный сайт с одним окном диалога. `parse.js` строит схему запроса и инструкции модели на основе справочников городов и категорий. Модель извлекает условия из всей истории; сервер подбирает по типам характеристик из `data/categories.json` и перепроверяет сумму, состав и город по структурированным объявлениям. Заголовки и описания не передаются модели как инструкции.

## Запуск

Нужен Node.js 18 или новее, устанавливать пакеты не нужно.

```sh
npm start
```

Откройте <http://127.0.0.1:4173>. Настройки API читаются из локального `.env`, который исключён из Git. Переменные окружения процесса имеют приоритет над локальным файлом. Ключ использует только сервер и не отправляется браузеру. На PowerShell можно запустить `node server.js`, если политика выполнения блокирует `npm.ps1`.

## Данные

В справочниках 6 городов и 7 категорий. Каталог расширен до 250 синтетических объявлений — это верхняя граница схемы. Помимо столов, кресел и ламп есть диваны, кровати, шкафы и холодильники; у каждой из четырёх дополнительных категорий по 4 варианта в каждом городе, с разными размерами, вместимостью и характеристиками. Москва, Санкт-Петербург и Казань имеют объявления всех семи категорий.

Для добавления города или категории обновите `data/cities.json` или `data/categories.json` и затем каталог. Парсер и фильтр не содержат списков городов, категорий или имён характеристик в коде: поля выводятся из этих файлов. Схемы справочников и каталога допускают новые IDs и атрибуты. Синтетический каталог можно пересоздать командой `node scripts/generate-expanded-catalog.js`.

## Проверки

```sh
npm test
```

Тесты используют локальные данные и не расходуют запросы к модели. Они охватывают новые города и категории, универсальные типы характеристик, единицы, интервальные границы, отсутствие значений, точную сумму, уточнения и устойчивость к инструкциям внутри объявлений.
