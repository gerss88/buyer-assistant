# Контракты проекта (ИИ-помощник покупателя)

## 1. CLI-контракт
Запуск: `./run --catalog data/catalog.json`
- Вход: JSON из `stdin`
- Выход: ровно один JSON в `stdout`
- Логи и ошибки: в `stderr`

## 2. Схема входных данных (stdin)
```json
{
  "messages": [
    {"role": "user", "text": "Стол не шире метра, кресло и лампа. Таганрог. До 15 000 ₽ за всё."}
  ]
}
