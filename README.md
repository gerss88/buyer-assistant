# 🛒 ИИ-помощник покупателя

Проект для хакатона ЮФУ. Помощник понимает запрос покупателя на естественном языке, ищет подходящие товары в учебном каталоге и собирает комплекты (например, стол, кресло и лампа), которые укладываются в заданный бюджет.

## 🚀 Установка и запуск

1. **Клонируйте репозиторий и перейдите в папку:**
   git clone https://github.com/ваш_ник/buyer-assistant.git
   cd buyer-assistant

2. **Создайте виртуальное окружение и установите зависимости:**
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt

3. **Настройте окружение (Ключи для LLM):**
   Создайте файл .env в корне проекта (он уже добавлен в .gitignore) и впишите туда данные для доступа к модели Gemma 4 31B (ключи выдает организатор):
   LLM_BASE_URL=https://api.организаторов...
   LLM_MODEL=gemma-4-31b
   LLM_API_KEY=ваш_ключ

## 💻 Запуск решения (CLI)

Решение читает один JSON из stdin и возвращает один JSON в stdout. Логи направляются в stderr.

Запуск на официальных примерах:
./run --catalog data/catalog.json < examples/01-selection/request.json

Запуск на своем запросе:
echo '{"messages":[{"role":"user","text":"Стол не шире метра, кресло и лампа. Таганрог. До 15 000 ₽."}]}' | ./run --catalog data/catalog.json

## 🖥 Веб-интерфейс (Streamlit)

Для запуска графического интерфейса используйте:
streamlit run app/streamlit_app.py

## 🧠 Где используется языковая модель (LLM)

Парсинг запроса: Модель Gemma 4 31B (через API) извлекает из естественного языка город, бюджет, категории и ограничения (например, ширину стола). Код парсера находится в llm_client.py.
Логика подбора (Solver): Поиск, фильтрация и подсчет бюджета выполняются на чистом Python (solver.py) без участия ИИ. Это гарантирует, что модель не выдумает несуществующую цену или город.
Защита от инъекций: В системном промпте прописано правило игнорировать инструкции из поля description объявлений. Бэкенд берет цену и город только из соответствующих полей каталога.

## 🧪 Тестирование

Запуск автотестов (QA):
pytest -v

## 📂 Структура проекта

run — Исполняемый файл для запуска CLI.
main.py — Точка входа, связывает парсер, solver и вывод.
catalog.py — Загрузка и валидация каталога.
solver.py — Алгоритм подбора комплектов (фильтры, бюджет).
llm_client.py — Взаимодействие с API модели (и fallback на регулярки).
prompts/ — Системные промпты для LLM.
tests/ — Тесты (pytest).
data/ — Учебный каталог и справочник городов.
