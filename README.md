# ИИ-помощник покупателя

В репозитории сохранена исходная CLI-версия на Python и добавлена новая локальная веб-версия в каталоге [`v2/`](v2/README.md).

## Новая версия: локальный сайт

Новая версия использует Node.js 18+, не требует установки npm-пакетов и запускает локальный чат с подбором комплектов из расширенного каталога.

```powershell
cd v2
Copy-Item .env.example .env
# Заполните LLM_API_KEY и настройки API в .env
npm start
```

Откройте <http://127.0.0.1:4173>. Чтобы запустить тесты версии 2:

```powershell
cd v2
npm test
```

Подробнее о данных, настройке модели и проверках — в [README версии 2](v2/README.md).

## Исходная версия: Python CLI

CLI принимает JSON с сообщениями из stdin, подбирает товары из каталога и печатает один JSON-ответ в stdout. Подбор и проверка бюджета выполняются локально в Python.

```sh
./run --catalog data/catalog.json < examples/01-selection/request.json
```

Запрос должен иметь вид `{"messages":[{"role":"user","text":"..."}]}`. Чтобы запустить тесты, установите зависимости из `requirements.txt` и выполните:

```sh
pytest -v
```

### Настройка LLM в Python CLI

Парсер сначала обращается к настроенному OpenAI-совместимому API модели Gemma 4 31B. Скопируйте `.env.example` в `.env` и укажите URL API, имя модели и ключ:

```dotenv
LLM_BASE_URL=https://api.example.com/v1
LLM_MODEL=gemma-4-31b
LLM_API_KEY=your-api-key
LLM_TIMEOUT_SECONDS=5
```

`LLM_BASE_URL` — базовый URL OpenAI-совместимого API; клиент добавляет `/chat/completions`, если в URL ещё нет этого пути. Используйте адрес и имя модели, выданные вашим API-провайдером. `.env` исключён из Git.

Если ключ или URL не настроен, либо API недоступен, вернул ошибку, невалидный JSON или ответ не прошёл проверку схемы, CLI использует локальный regex-парсер. Каталог не отправляется LLM: описания объявлений остаются недоверенными данными и используются только локальным подборщиком.
